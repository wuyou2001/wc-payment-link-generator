# WooCommerce 付款链接生成器 (wc-payment-link-generator)

支持在 WooCommerce 后台生成自定义金额付款链接，具备短链接模式、多设备与移动端 Cookie 丢失容错、变体产品属性自动选择、订单验证跳过与全主题纯净结账体验，并内置 GitHub 一键自动升级更新系统。

---

## ✨ 核心特性

- **自定义金额短链接**：生成隐藏真实参数的优美短链接，在设定的有效期内多次打开始终有效。
- **物理数据库双重持久化**：采用 `wp_options` + 内存 Transient 双重落盘，彻底解决 Redis 重启、缓存插件清理导致的“链接失效”问题。
- **移动端与内嵌浏览器无缝兼容**：多层级 Token 传递与购物车安全初始化，防止 302 重定向过程丢失 Cookie 导致购物车为空。
- **变体商品智能属性解析**：当变体产品包含未设定的属性时，系统自动识别并补全有效属性组合，避免下单受阻。
- **页面内容精细化可选保留**：
  - 保留产品信息明细
  - 保留账单地址（自适应 1000px 布局且支持免必填极速提交）
  - 保留全站页首页脚
  - 保留隐私政策条款
- **全主题自适应纯净支付模式**：自动隐藏不必要的干扰区块，适配任何 Block 块主题与传统 PHP 主题。
- **内置 GitHub 自动更新 (WordPress Update API)**：绑定公开仓库 `wuyou2001/wc-payment-link-generator`，发布新版本 Release 后，所有已安装站点可在后台一键在线升级。

---

## 📦 安装与使用

1. 下载最新的 `自定义价格付款链接-短链接版.zip`。
2. 登录 WordPress 后台 → **插件** → **安装插件** → **上传插件**。
3. 激活后，在后台左侧菜单即可找到 **“生成付款链接”** 进行使用。

---

## 🚀 版本发布与自动更新指南

当您需要为已安装的客户或站点推送新版本时：
1. 更新代码主版本号（例如 `v2.0.2`）。
2. 在本 GitHub 仓库的 **Releases** 页面点击 **Draft a new release**。
3. 输入标签版本号（如 `v2.0.2`），上传打包好的 zip 文件作为资产。
4. 点击 **Publish release** 即可！所有站点的 WordPress 后台将自动检测到更新并支持一键升级。
